# Thread 折叠功能

## 背景

多封往来邮件的 Thread 在信息密集场景下会显著增加阅读成本；通过对已读邮件进行折叠，仅突出关键节点（首封、最新、未读），在保证上下文连续性的同时，降低用户滚动与认知负担。

## 折叠规则

### 基础规则

- **Thread ≤ 4封**：全部展开
- **Thread > 4封**：根据场景应用不同折叠策略

### 折叠策略

| 场景 | 展示方式 |
|------|---------|
| 有未读邮件 | 第1封（展开） + 中间已读（折叠） + 未读前最近1封已读（收起） + 全部未读（展开） |
| 全部已读 | 第1封（展开） + 中间（折叠） + 倒数第2封（收起） + 最后1封（展开） |

### 术语说明

- **展开**：显示完整正文
- **收起**：仅显示 header（发件人 + 时间 + 摘要），点击可展开
- **折叠**：合并为数字 badge，点击可展开全部
- **展开即已读**：邮件展开后自动标记已读

## 折叠区 UI

### 样式

- 左侧：圆形数字 badge，显示折叠数量
- 右侧：虚线延伸至下一封邮件
- 点击数字 badge → 展开所有折叠邮件

### 状态

- 默认折叠态
- 点击后展开，不可再次折叠（同 Gmail）

### 单封邮件交互

- 点击邮件 header → 展开/收起该邮件正文
- 收起态显示：发件人 + 时间 + 正文首行摘要
